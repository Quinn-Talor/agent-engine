# 劳动争议咨询方法

由律所的劳动法团队维护，改这里不需要改代码。

1. 查明事实：入职时间、月工资、欠薪月数、是否已离职。缺任何一项先问委托人。
2. 检索依据：欠薪 → 《劳动合同法》第三十条；被迫解除 → 第三十八条；经济补偿 → 第四十六条、第四十七条；
   仲裁时效 → 《劳动争议调解仲裁法》第二十七条。
3. 检索类案：委托案例研究员查同类裁判，作为参考，不作为依据。
4. 计算补偿：用 calc_compensation，离职日期按委托人计划的日期。
5. 出具意见书：每条分析写明依据；不承诺结果；写明下一步（书面通知解除、申请劳动仲裁、保留证据）。
